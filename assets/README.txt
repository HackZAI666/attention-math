Attention image assets

1) Pumpkin commemorative trophy
   File: assets/pumpkin_trophy.png
   Format: PNG, transparent background recommended
   Recommended canvas: 512 x 512 px
   Used in: the challenge reward panel and Dashboard > Honors.

2) Strongest Brain rank emblem (future rank; not currently obtainable)
   File: assets/rank_strongest_brain.png
   Format: PNG, transparent background recommended
   Recommended canvas: 512 x 512 px
   Used in: Dashboard > Rank Rules, beside the under-development tier.

If either file is absent, the site displays a built-in placeholder instead of a broken-image icon.
Do not overwrite assets/logo.png.


PLAYER TITLE EMBLEMS (optional images)
Place these files directly in this assets folder. Use transparent PNGs, recommended 640 x 160 px. Do not overwrite logo.png.
- title_halloween.png — Halloween title unlocked by earning the Pumpkin Learner trophy.
- title_expert.png — 高手 title; unlock condition is 30 ranked stars (ranked play is not active yet).
- title_strongest_brain.png — 最强大脑 title; reserved for the under-development 50-star rank and currently cannot be earned.
If a title image is not present, a neutral text placeholder is shown. A title is only shown next to the player's name after it is unlocked and equipped in Dashboard > Titles.
